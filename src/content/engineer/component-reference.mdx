## Code

Syntax highlighting happens at build time, with no JavaScript shipped:

```ts
export function slugify(input: string): string {
  // "C++" and "C" used to collapse to the same slug.
  return input.replace(/\+\+/g, '-plus-plus');
}
```

Inline `code` should sit in a hairline box without stray backticks around it.
